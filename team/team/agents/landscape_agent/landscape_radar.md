# Landscape Radar — November 2026

This is a qualitative radar, not a score.

| Signal | Current position | Why it matters |
|---|---|---|
| Agent capability | Accelerating | Technical progress does not by itself prove workflow reliability. |
| Enterprise agent scaling | Early and uneven | Large enterprises scale faster than smaller organizations. |
| Logistics production evidence | Growing | Real logistics workflows are in production. |
| Autonomous financial authority | Limited direct evidence | Adjacent workflows do not establish invoice-payment autonomy. |
| Interoperability standards | Rapidly strengthening | MCP and A2A may reduce integration friction and improve portability. |
| Vendor/ecosystem breadth | Expanding | More options also create evaluation and lock-in complexity. |
| Reliability/control | Improving but unresolved | Human validation and constrained authority remain important. |
| Economics | Evolving | Fully loaded cost remains organization-specific. |
| Governance/regulation | Increasingly consequential | Authority, auditability and data handling can change choices. |
| Freight-invoice-specific evidence | Insufficient for broad autonomy | Closely related logistics cases are stronger than direct payment evidence. |
