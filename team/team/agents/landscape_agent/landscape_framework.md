# Landscape Framework

| Dimension | Question | Typical evidence |
|---|---|---|
| Technology maturity | What can agentic systems reliably do now, and where do they still fail? | Independent evaluations, technical reports |
| Enterprise diffusion | Are organizations experimenting, piloting, or scaling? Does size matter? | Enterprise surveys |
| Application maturity | Is there production evidence for the specific or closely analogous workflow? | Operator cases, peer evidence |
| Incumbent alternatives | What non-agentic approach already solves the problem? | Workflow/RPA/document automation evidence |
| Competing architectures | What alternative agent/orchestration approaches could deliver the capability? | Product/technical ecosystem evidence |
| Complementary technology | What must work around the agent? | APIs, document AI, identity, observability, ERP/TMS integration |
| Standards/interoperability | Are protocols reducing integration friction or lock-in? | Standards project releases |
| Vendor/ecosystem | Is the supplier/tool ecosystem broadening and stabilizing? | Multi-vendor/operator evidence |
| Cost/performance | Are reliability, latency, compute and review economics improving enough? | Benchmarks, internal TCO, operator results |
| Regulation/governance | What rule, standard or control expectation could materially change deployment? | Official regulatory/standards sources |

## Evidence discipline
Every consequential signal gets two labels.

**Scope:** technology-general / agentic-AI-specific / application-specific / industry-specific / comparable-peer-specific.

**Source type:** independent/academic / standards-regulatory / industry-consulting / vendor-operator / organization evidence / inference.

Broad adoption is never sufficient proof of application maturity.

## Primary conventional alternative
For the 3PL freight-invoice case, compare agentic orchestration against deterministic document extraction + rules/tolerance matching + ERP/TMS integration + human exception review.
