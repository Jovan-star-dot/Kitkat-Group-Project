# Emerging Technology Diffusion Agent

Lab 5 specialist for MASY1-GC 1800 Emerging Technologies.

This agent applies Rogers' diffusion concepts to distinguish diffusion of an emerging technology generally from diffusion of a specific application and from the timing implication for a particular organization. It assesses adopter stage, Rogers' five diffusion characteristics, accelerators/inhibitors, evidence quality, and monitoring triggers.

**Boundary:** informs timing and peer-position judgment; does not make the full adoption decision.
